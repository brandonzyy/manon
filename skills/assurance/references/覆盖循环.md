# P5 覆盖循环 —— 量读数、排目标、补断言

**这一节取代了原来独立的 `/tc` skill。** 覆盖率循环本来就是补齐序列 P5 的内部动作，
拆成一个独立入口的代价是没人在读数之后被指向它——实测 200+ 个会话里 `/tc` 零调用，
而它被三个在用的 skill 引为配对。工具是 [`../scripts/coverage_targets.py`](../scripts/coverage_targets.py)
（纯 stdlib，不碰 git）。

## 一、先出读数

```bash
# Go：-count=1 是必需的。测试缓存会把别的包旧版本的代码块位置一并算成未覆盖，
#     方向是报**高**，baseline 被录高，真实回退就藏在虚高的余量里。
go test -count=1 -coverprofile=coverage.out ./...
# 前端：让它报全部源文件，别只报被测试 import 过的
vitest run --coverage        # 配 coverage.all = true

python3 <SKILL_DIR>/scripts/coverage_targets.py <项目路径> [--repo-id ID] [--top N]
```

**退出码 2 是判据不成立，不是「零个待补目标」。** 四条硬判据，撞上哪条它就退 2 并点名：

| 判据 | 撞上了说明 | 放行开关 |
|---|---|---|
| 找得到覆盖数据 | 没跑过覆盖率——**空结果会被读成「已经覆盖完了」** | 无，必须先跑 |
| 读数不比源码旧 | 源码改过没重跑，读数偏**高** | `--allow-stale` |
| 分母自证 | 覆盖数据只含被测试 import 过的文件，百分比在子集上算 | `--allow-subset` |
| fan-in 已知 | 图谱 API 没通——**未知记成 0 会把重要目标降权到最后** | 输出里是 `null` |

分母那条的外部参照是 `os.walk` 数磁盘源文件数，**在被检查的机制之外**。
覆盖工具自己报的文件数不能给自己作证。

## 二、排目标

排序是 `fan_in 权重 × 覆盖权重`，再按未覆盖量。三条与上游 `/tc` 不同的口径：

1. 🔴 **零调用方的文件不进目标**，单列 `dead_candidates`，判定写着「先问该不该退役」。
   **给零消费者的代码补测试是给它背书**，还会让它从死面棘轮里消失——判例见
   `仓内事故页「给死函数写测试可以让它从棘轮里消失」`。
   真要补加 `--include-dead`，但先想清楚为什么。
2. **fan-in 未知的整体后置**，不冒充高分也不冒充低分。
3. **截断留痕**：`dropped` 里报低覆盖文件总数、进入排序的、因 top-N 未列出的。
   静默截断会被读成「全覆盖到了」。

## 三、补断言

补测试的判据不是「让百分比涨」，是**断言落在判据上**。两条从变异测试里长出来的：

* **断言落在「这条路走没走过」的痕迹上，不是落在结果上。** 两条不同路径可能给出
  相同结果（亲和命中与兜底选出同一条渠道）；鉴权类断言不能只断状态码——
  `common.ApiErrorMsg` 返回的是 200 + `success:false` 信封，只断状态码的用例恒真。
* **`err == nil && x != ""` 这一族必须配一条 `err != nil` 的用例。** err 非空时后面那个
  对象通常是 nil，把「与」写成「或」就是空指针，而只测正路的话那个改法全绿。

**测试夹具会静默削弱别的测试。** 立一个共享的 DB/全局夹具之前，先查同包里有没有测试
是靠「越过守卫去查 nil 会当场 panic」来判失败的——留下一个设好的实例，那些用例
**失去杀伤力且仍然全绿**。夹具要在 `t.Cleanup` 里还原，并写一句注释点明这件事。

**同包测试助手一律带文件名词干前缀。** 两条分支各写一个 `newTestCtx`，各自全绿、
合并即编译不过。包级 `TestMain` 同理，一个包只能有一个。

## 四、收口

1. **重录棘轮**（不重录等于没做）：
   ```bash
   python3 <你的产出器> <棘轮名> | <你的棘轮工具> update <棘轮名>
   ```
   棘轮两个方向都红：变多是门禁，**变少而没重录也是红**。
2. **存量变少必须先证明数法没变。** 说得出是哪个动作造成的（补了断言 / 退役了代码），
   说不出就是量具变了，此时重录的是一个虚低 baseline。
3. **提交由人来做，一律 `git commit -F msg -- <显式路径>`。** 共用工作树上裸
   `git commit` 提交整个索引，会把别的会话暂存的东西一起带走（判例 `实测判例`）。
   `coverage_targets.py` 因此完全不碰 git——上游 `/tc` 的 `tc-commit.py` 正是裸提交。
